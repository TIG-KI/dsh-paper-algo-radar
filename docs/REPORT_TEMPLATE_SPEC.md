## 0. 公共约定（所有章节适用）

### 0.1 数据一致性
- 报告在**一次生成内复用同一份库快照**（同一 store 视图），不得中途重读。
- 报告头写死：`generatedAt`、`dictVersion`、库规模、`referenceYear`、`scope`。

### 0.2 数值与格式

| 项 | 规则 | 例 |
|---|---|---|
| 计数 | 整数，无千分位 | `124` |
| 百分比 | 1 位小数 | `40.0%` |
| **分母** | 凡出现百分比，同段必须给出 `分母=N` | `覆盖率 40.0%（分母=5 篇）` |
| 年份 | `YYYY` | `2024` |
| 时间 | `YYYY-MM-DD HH:mm` + 时区 | `2026-10-23 00:28（Asia/Shanghai）` |
| 空值 | `—` | 无年份 → `—` |
| 0 与未知 | **必须区分**：0 显示 `0`，未知显示 `—` | 提及数 0 ≠ 未统计 |
| 单位 | 篇 / 次 | — |

### 0.3 表格与排版

- 表格最多 **6 列**；超 6 拆两张表。
- 表头中文；数字列右对齐（Markdown `---:`）。
- 排序一律走 R13：论文数 desc → 提及数 desc → 规范名 asc（码位比较）。
- 章节标题格式：`## N. 标题`；小节 `### `。
- **不使用 HTML、不使用 emoji**（保证跨预览一致与可复现）。
- 口径说明用引用块 `> 口径：…`。

### 0.4 长度上限

| 项 | 上限 |
|---|---|
| 全文 | ≤ 400 行 |
| 单章 | ≤ 80 行 |
| 摘要章 | ≤ 5 条 × 40 字 |
| 附录排行 | ≤ 200 行，超出写 `（已截断：显示前 200 / 共 N）` |

### 0.5 报告头（不计章，两套模式共用）

```
# 论文算法雷达 · 汇报报告            ← mode=review；decide 为「决策报告」
生成：2026-10-23 00:28（Asia/Shanghai） · 口径 2026.10.2 · 参考年 2026
库：5 篇 · 13 个算法 · 124 次提及 · 摘要级 4/5 · 陈旧 0 篇 · 可重算 0 篇
范围：全库                          ← 或 领域=<name> / 年份=<Y1>–<Y2>
```

字段来源：`radar_status`（papers / algorithms / abstractOnly / dictVersion / staleCount / staleRecomputable）+ `radar_fields`。

## 1. `review` 十章字段定义

### 1.1 第 1 章 摘要

- 3–5 条，**每条必须是数字陈述**，不写推断。
- 固定句式（按顺序取用，缺数据则跳过该条）：

| # | 句式 | 取数 |
|---|---|---|
| 1 | 共登记 N 篇（全文 F / 摘要 A），覆盖 K 个算法、M 个领域。 | status + fields |
| 2 | 出现最多的是 `X`（N 篇 / M 次，覆盖 P%）。 | ranking[0] |
| 3 | 时间跨度 Y1–Y2；无年份 N 篇。 | trends |
| 4 | 输入质量：摘要级 X%（>50% 时追加「排行可能偏差」）。 | status |
| 5 | 口径 `dictVersion`；陈旧 N 篇（可重算 M 篇）。 | status |

- 上限：5 条；全文 ≤ 200 字。

### 1.2 第 2 章 数据画像

两列表格：`| 指标 | 值 |`

| 指标 | 值 | 来源 | 空值 |
|---|---|---|---|
| 论文数 | N 篇 | status.papers | `0` |
| 全文级 / 摘要级 | F / A | status | `0 / 0` |
| 算法数 | K | status.algorithms | `0` |
| 领域数 | M | fields.length | `0` |
| 提及总数 | X 次 | status、ranking 汇总 | `0` |
| 时间跨度 | Y1–Y2 | trends | 无年份全无 → `—` |
| 词典口径 | 2026.10.2 | status.dictVersion | `—` |
| 陈旧提及 | N 条 | status.staleCount | `0` |
| 可重算论文 | M 篇 | status.staleRecomputable | `0` |
| 来源构成 | `pdf 40 · doi 12 · search 9 · …`（7 类按篇数降序，为 0 省略；`null` 另写「未知 N 篇」） | papers.source 分组 | `—` |
| 已读 / 未读 | `D / U`（未读 = `toread` + `reading`，在读 K 篇并入未读并在括号注明） | papers.status 分组 | `0 / 0` |
| 状态未知 | X 篇（`status=null`，早于状态追踪，不计入已读/未读） | papers.status=null | `0` |

### 1.3 第 3 章 算法排行 Top 10

6 列：`| # | 算法（类型·分类）| 论文数 | 提及数 | 覆盖率 | 首见年 |`

- 来源：`radar_ranking`（`rankBy=papers`，`limit=10`）。
- 算法名列格式：`CNN（DL · 架构）`；无 family 时只写 `CNN（DL）`。
- 覆盖率：`coverage` 字段；分母写在表下 `> 分母 = N 篇（scope 内）`。
- 空值：`firstYear=null` → `—`；分母 0 → 覆盖率 `—`。
- 表下追加（命中时）：`> 含旧口径数据 N 条（dictVersion 混合）`。
- 表下追加（未读 N > 0 时，FR-14.4 / W2.2）：`> 排行含未读 N 篇（toread + reading），未按阅读状态过滤。`

### 1.4 第 4 章 类型分布

3 列：`| 类型 | 论文数 | 占比 |`，固定三行 DL / ML / MATH（为 0 也显示）。

- **口径**：按「算法 × 论文」去重后聚合，**一篇论文可计入多个类型**；分母 = 三行之和，不是论文总数。
- 表下必须写：`> 一篇论文可跨多个类型，故合计大于论文数（分母=N）。`

### 1.5 第 5 章 时间线

表 A（3 列）：`| 年份 | 新增论文 | 累计论文 |`，按年份升序，只列有数据的年份。

表 B（3 列）：`| 算法 | 首见 | 最近 |`，取 Top 10 内算法。

- 来源：`radar_trends`（`ids` 取 Top 10）。
- 表下：`> 另有 N 篇无年份论文未计入（undatedCount）。`（N=0 时省略）

### 1.6 第 6 章 领域分布

3 列：`| 领域 | 论文数 | 占比 |`，按论文数降序；**「未分类」单列一行且排最后**。

- 来源：`radar_fields`。
- 分母 = 论文总数；表下：`> 论文可多标签，故合计大于论文数（分母=N）。`

### 1.7 第 7 章 代表性论文

4 列：`| 领域 | 论文 | 年份 | 算法数 |`

- 每领域取前 2 篇，排序键：`hitCount` desc → `updatedAt` desc。
- 摘要级论文在标题后加 `（摘要级）`；无年份 → `—`。
- 表下：`> 按命中算法数选取，偏好长文；仅供参考。`
- 领域 ≤ 2 个时每领域取前 3（总数 ≤ 6）。

### 1.8 第 8 章 最近 N 天新增

3 列：`| 日期 | 论文 | 算法数 |`，按 `readAt` desc，最多 10 行。

- N = `windowDays`（默认 30）。
- **用 `readAt` 而非 `updatedAt`**（重算会刷新 updatedAt，会污染"新增"语义）。
- 无新增：写一行 `最近 N 天无新增。`

### 1.9 第 9 章 可信度与局限

两列：`| 项目 | 说明 |`，至少 5 行，全部由规则生成：

| 项目 | 触发条件 | 说明 |
|---|---|---|
| 摘要级占比 | 总 <100% | 「摘要级 N/M；摘要级论文的算法数天然偏少」 |
| 样本量 | <20 篇 | 「样本量小，排行不具统计意义」 |
| 旧口径 | staleCount>0 | 「N 条提及为旧口径，跨版本比较需谨慎」 |
| 无正文 | 无正文 >0 | 「M 篇无正文，不可重算」 |
| 领域覆盖 | 领域数 ≤2 | 「领域标签过少，分布不可用于推断」 |

### 1.10 第 10 章 附录

A. 完整排行（4 列）：`| # | 算法 | 论文数 | 提及数 |`，≤200 行。
B. 论文清单（4 列）：`| 标题 | 年份 | 领域 | 算法数 |`，按 `readAt` desc，≤200 行。

## 2. `decide` 五章字段定义

### 2.1 第 1 章 缺口清单（结论先行）

4 列：`| 编号 | 缺口 | 严重度 | 证据摘要 |`

- 只列**命中**的缺口；全部不命中时写一句「未发现缺口」，不造条目。
- 严重度：高 / 中 / 低（见 §3 规则）。

### 2.2 第 2 章 缺口证据

每个缺口一个小节（`### G1 …`），固定三段：

```
判定规则：摘要级占比 > 50%，或 无正文篇数 > 0
实测：摘要级 4/5（80%）；无正文 5 篇
命中：是
```

### 2.3 第 3 章 方向与动作

每个缺口两句：**方向**（领域/类型映射，一句话）+ **动作**（可执行项）。

- G1 的动作附可补清单，5 列：`| 标题 | 年份 | 算法数 | 深度 | 登记日 |`，按算法数降序取前 10。
- G2 的动作给出该领域现有论文作起点（≤3 篇）。
- G3 无清单，只给方向（需外部检索）。
- G5 的动作写「`/radar reextract` 预览 → 确认」。

### 2.4 第 4 章 口径附录

复用 §1.9 的表格，一字不改（同源函数）。

- W2.2 追加一句固定文案（`decide` 不显示来源分布，但要说明它没参与判定）：
  `> 来源渠道与阅读状态不参与缺口判定（G1–G7 只看数量与结构）。`

### 2.5 第 5 章 未评估项

3 列：`| 项目 | 原因 | 数据 |`

- 领域论文数 = 1 → 「数据不足，不评估该领域」
- 库 < 20 篇时的类型失衡 → 「库太小，类型占比不作结论」
- 无年份论文 → 「无年份，不进时间维度」

### 2.5bis `insight` 模式（领域洞察，W2.1 新增）

> 详细决策见 [FEATURE_INSIGHT.md](C:/Users/26580/Documents/1_Mycode/dsh_plugin_design/docs/FEATURE_INSIGHT.md) §3；此处只给开发要落地的字段级差异。

- **前置**：`mode=insight` 必须给 `field`；`scope` 固定为领域；缺 `field` → `VALIDATION`。
- **五节**：1 领域画像 / 2 算法热度 Top10 / 3 算法组合 Top10 / 4 组合证据 / 5 口径与局限。

| 节 | 列 / 内容 | 关键口径 |
|---|---|---|
| 1 画像 | 指标 \| 值（篇数、占全库比例、时间跨度、摘要级占比、算法种数） | 占全库比例必须给分母 |
| 2 热度 | # \| 算法（类型·分类）\| 论文数 \| 提及数 \| **领域内覆盖率** \| 首见年 | 分母 = 领域篇数；Top1 与全库不同时显式指出 |
| 3 组合 | # \| 组合 \| 同现篇数 \| lift \| 同现率 | 最小同现 3 篇；排序 篇数 desc → lift desc |
| 4 证据 | 每个 Top3 组合：3 篇同现论文 + 每篇每算法 1 条片段 | 片段不保证相邻；「共现 ≠ 结合」 |
| 5 口径 | 复用 §1.9 表 + 三条固定项（样本量 / 库内偏差 / 共现语义） | 领域 <5 篇只出 1、5 两节 |

#### 2.5ter `insight` 的 `venueScope` 分层（W2.2 新增，FR-16.3）

| 项 | 规则 |
|---|---|
| 默认 | `venueScope=all` → 第 2 节单表，与 W2.1 完全相同（回归基线） |
| `allowlist` | 第 2 节拆两张表：「白名单内 Top10」+「白名单外 Top10」，各 ≤10 行，第 2 节总行数仍 ≤80 |
| 分母 | 两张表的覆盖率**各自用本层篇数作分母**，不得混用（表下写 `> 分母 = 白名单内 N 篇`） |
| venue 为空 | 归「白名单外」，表下追加 `> 其中 venue 未标注 M 篇`（M>0 时） |
| 空白名单 + `allowlist` | `VALIDATION`（不降级、不出空报告） |
| 时间窗 | 本批不支持：`yearFrom`/`yearTo`/`windowDays` 在 `insight` 下 → `VALIDATION`（Q17） |
| 固定声明 | 第 2 节表下必须有一句：`> 白名单只表示检索范围，不表示论文质量。` |
| 第 3 节 | 组合**不按 venue 分层**（同现样本会被切得太碎），沿用领域全集；第 5 节补一句「组合基于领域全集，未按白名单过滤」 |

## 3. 缺口规则参数（与 R13 / FR-13.4 一致）

| 缺口 | 参数 | 默认值 | 判定 |
|---|---|---|---|
| G1 | 摘要级占比阈值 | 50% | > 50% 或 无正文 > 0 |
| G2 | 领域分级 | 1 / 2 / ≥3 | 1 不评估；2 薄；≥3 正常 |
| G3 | 库规模门槛 + 类型占比 | 20 篇 / 10% | 库 ≥20 且某类型 <10% |
| G4 | 年份滞后 | 2 年 | 最新年 < `referenceYear` − 2 |
| G5 | 陈旧篇数 | >0 | `stalePapers > 0` |

> 「未分类」不计入 G2；示例数据（`isSample`）默认不参与任何统计与报告。

## 5. 空态与边界

| 条件 | review 输出 | decide 输出 |
|---|---|---|
| 0 篇 | 头 + 第 2 章（全 0）+ 第 9 章 + 第 10 章（空表） | 第 4 章 + 第 5 章 |
| 1–4 篇 | 头 + 第 2 章 + 第 9/10 章 + 一句「数据不足，不出结论」 | 同上（G1/G2 仍可命中） |
| 5–19 篇 | 全部十章；第 9 章必含「样本量小」 | 全部五章 |
| ≥20 篇 | 全部十章 | 全部五章 |
| 分母 = 0 | 比率显示 `—` | 同 |
