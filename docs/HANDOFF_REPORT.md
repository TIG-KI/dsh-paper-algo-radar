1. **签 P-10 / P-11**：不签，开发就不能确定"润色谁执行"和"报告写哪"。
2. **确认 P0 归属（§16-Q11）**：不处理也能开发，但 W2.1 的范围承诺会带着 45% 的 P0——如果这次不裁，下次排期还会吵。
